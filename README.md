# DiscloAI WordPress Plugin

WordPress plugin for EU AI Act Article 50 compliance disclosures.

Enqueues the DiscloAI CDN script via `wp_enqueue_script` and provides a
WP Admin settings page to configure your `siteId`.

## Installation

1. Download the latest release `.zip`
2. WordPress Admin → Plugins → Add New → Upload Plugin
3. Activate and go to **Settings → DiscloAI** to enter your Site ID

## Development

Requires PHP 7.4+ and WordPress 6.0+.
